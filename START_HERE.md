## 📞 EMERGENCY REFERENCE

### Server won't start
→ Check: NODE processes
→ Fix: Kill existing npm process, restart

### MongoDB not connecting
→ Check: .env file
→ Fix: Verify connection string

### Page shows blank
→ Fix: Clear browser cache (Ctrl+Shift+R)
→ Fix: Clear localStorage (F12 → Console → localStorage.clear())

### API not responding
→ Check: Server running on port 5000?
→ Check: MongoDB connected?
